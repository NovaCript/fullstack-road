# ⚠️ Важно

В роликах я использую сервис **picsum.photos** для получения картинок, который ныне перестал работать в России.

### Решение
Использование сервиса [via.placeholder.com](http://via.placeholder.com). Например, чтобы получить картинку размером `640x360`, достаточно выполнить запрос:
`http://via.placeholder.com`
*(Примечание: сервис часто работает нестабильно).*

### Альтернативные варианты:
* [placehold.co](https://placehold.co)
* [dummyimage.com](https://dummyimage.com)
* [picsum.photos](https://picsum.photos) (через VPN)
* [fakeimg.pl](https://fakeimg.pl)
* [placebear.com](https://placebear.com)

Удачи, и не стесняйтесь задавать вопросы, если что-то будет неясно!
